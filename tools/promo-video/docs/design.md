# 制作设计说明

对应 [script.md](script.md) 的全片制作方案。15 秒样片（脚本 0:00–0:15）已按本方案实现，用来验证方法。

## 样片验证了什么

| 方法 | 样片里的做法 | 自检结果 |
| --- | --- | --- |
| 单一时间轴 | `src/sample/timeline.ts` 同时驱动画面和配乐合成，帧号只写一次 | 改时间点时，音画自动跟着动 |
| 节拍网格 | 120 BPM，1 拍 = 15 帧；入场、卡住、撞击都落在拍上 | 撞击落在第 360 帧（12.000 秒） |
| 音画同步 | 对成片音轨与源音频做交叉相关 | 在 0.5s / 4s / 12s / 13.27s 四处偏移均为 0 样本 |
| 品牌母题 | 两半括号在静默中从对角飞入，在撞击帧合拢成标志 | 合拢后的比例按官方 `wordmark.svg` 坐标换算 |
| 响度 | BS.1770 积分响度归一 + 前视限幅 | 约 -16 LUFS，峰值 -1 dBFS |
| 静默 | 撞击前一拍内容全部门控 | 11.55–11.98 秒为纯数字静音 |
| 两版交付 | `music` 属性控制，同一条时间线渲出 | 带配乐版 + 仅音效版 |

## 全片工程结构

```
src/
  theme.ts            产品色、字体、缓动
  components/         TerminalWindow、AgentCard、AppWindow、BracketMark …
  sample/             15 秒样片（冷开场 + 揭示）
  film/               全片：每章一个场景组件 + 共享 timeline.ts
scripts/
  sync-assets.mjs     素材同步（不入库）
  synth/              DSP 库 + 每段配乐
```

全片沿用样片结构，把 `timeline.ts` 扩展到 58 小节（3480 帧），每章一个 `<Sequence>`。冷开场和揭示直接复用样片组件。

## 每章的画面与镜头

| 章节 | 主镜头（每章只用一种主要动效） | 素材 |
| --- | --- | --- |
| ① 调度 Agent | 队友卡从任务行中被「拉出来」，连线点亮 | 2x 实拍对话 + 手绘队友卡 |
| ② 边干边说 | 真实交互按人的操作速度回放：输入、排队、提问卡、折叠 | 实拍逐状态截图 |
| ③ 模型分工 | 模型标志像发牌一样越落越快，满板停 0.5 秒，再收进设置页 | 产品内置厂商标志 + 实拍设置页 |
| ④ 可恢复 | 执行轨迹向下生长，断电全黑，原地续跑 | 手绘轨迹（产品页面里没有这个视图） |
| ⑤ 三种距离 | 产品原生晶格转场逐帧回放 | 实拍逐帧 |
| ⑥ 跨设备 | 设备连接图节点依次点亮，手机批准后桌面续跑 | 实拍设置页 + 390×844 手机视口 |
| ⑦ Bot 群聊 | 16 个角色从下方逐个冒头 | 产品内置角色图 |
| 收尾 | 每章代表元素四面飞入，括号合拢，全家福升起 | 复用前面各章的元素 |

真实界面统一用 `tools/promo-capture` 以 1110×705、DPR 2 采集，放进窗口框，按需推近。产品里不存在的视图（终端、轨迹）才手绘，手绘部分同样使用产品的色值和字体。

## 配乐系统

所有声音都由代码合成（`scripts/synth/`），没有任何外部音频文件，所以 B 站不会触发版权识别。

| 段落 | 小节 | 和声 | 乐器 |
| --- | --- | --- | --- |
| 前奏（已实现） | 1–6 | Am → F → E | 暗 pad、时钟滴答、hi-hat、riser，末拍静音 |
| 主题 A（已实现开头） | 7–30 | Am – F – C – G | 四拍底鼓、贝斯、拨弦琶音、侧链 pad |
| 断电 | 31–36 | 降到 Dm | 收窄 → 全停一小节 → 心跳式回归 |
| 主题 B | 37–48 | Am – F – C – G | 加 clap 和高音旋律，能量最高 |
| 温暖段 | 49–52 | F – G | 铃音 + pad，鼓退后 |
| 终章 | 53–58 | F – G – Am | riser → 最终和弦，自然衰减 |

拟音规则：画面里发生什么动作就配什么声音（打字配键盘、落位配木质 tick、选中配机械 click、模型发牌连发时音量逐级递减），不用游戏提示音。全画面级冲击全片只用 3 次（揭示、恢复、品牌落定）。
