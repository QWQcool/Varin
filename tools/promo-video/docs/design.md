# 制作设计说明

对应 [script.md](script.md) 的全片制作方案。15 秒样片（脚本 0:00–0:15）先验证方法，全片在此基础上完成。

## 成片自检与独立终检

| 项 | 结果 |
| --- | --- |
| 时长 / 规格 | 3465 帧 = 1:55.5，1920×1080 · 30fps · H.264 + AAC 48kHz 320k |
| 音画同步 | 两版成片在 4s / 12s / 22.3s / 43.5s / 67.5s / 72s / 92s / 108s 八处交叉相关偏移均为 0 样本 |
| 响度 | 带配乐 -15.3 LUFS、仅音效 -17.7 LUFS，峰值 -1 dBFS |
| 三处冲击 | 12s、72s、108s；12s 与 108s 前各有 0.5 秒纯数字静音（首尾呼应） |
| 独立终检 | 干净上下文的审查代理对照脚本与审美准则逐帧检查。阻断 1 项（④章恢复标签被场景时长截断）与应改 6 项（字号低于可读线、角色硬裁切、手机位置、Varin 登场、收尾能量、②章文案）均已修复并重渲 |
| 保留的小问题 | ⑦章群聊头像用产品内置角色，与①章粉丝向 Q 版形象不是同一张脸（有意区分产品自带角色与外部 Agent） |

## 样片验证了什么

| 方法 | 样片里的做法 | 自检结果 |
| --- | --- | --- |
| 单一时间轴 | `src/sample/timeline.ts` 同时驱动画面和配乐合成，帧号只写一次 | 改时间点时，音画自动跟着动 |
| 节拍网格 | 120 BPM，1 拍 = 15 帧；入场、卡住、撞击都落在拍上 | 撞击落在第 360 帧（12.000 秒） |
| 音画同步 | 对成片音轨与源音频做交叉相关 | 在 0.5s / 4s / 12s / 13.27s 四处偏移均为 0 样本 |
| 品牌母题 | 两半括号在静默中从对角飞入，在撞击帧合拢成标志 | 合拢后的比例按官方 `wordmark.svg` 坐标换算 |
| 响度 | BS.1770 积分响度归一 + 前视限幅 | 约 -16 LUFS，峰值 -1 dBFS |
| 静默 | 撞击前一拍内容全部门控 | 11.55–11.98 秒为纯数字静音 |
| 两版交付 | `music` 属性控制，同一条时间线渲出 | 带配乐版 + 仅音效版 |

## 全片工程结构

```
src/
  theme.ts            产品色、字体、缓动
  components/         TerminalWindow、AgentCard、AppWindow、BracketMark、BracketWipe、Chibi …
  sample/             15 秒样片（冷开场 + 揭示），全片开场直接复用
  film/               全片：timeline.ts、motion.ts、Type.tsx、Film.tsx、scenes/（一章一个组件）
scripts/
  sync-assets.mjs     素材同步（不入库）
  crop-chars.mjs      从 Q 版三视图裁出正面形象
  synth/              DSP 库 + sample15.mjs（样片）+ film.mjs（全片）
```

`src/film/timeline.ts` 以小节为单位定义九个场景边界与章节内节拍，画面和 `film.mjs` 配乐共用；章节之间用品牌括号遮罩转场（`BracketWipe`）。

## 每章的画面与镜头

| 章节 | 主镜头（每章只用一种主要动效） | 素材 |
| --- | --- | --- |
| ① 调度 Agent | 队友卡依拍飞入并连向对话，Q 版形象从卡片后冒头 | 官方 README 实拍对话 + 手绘队友卡 + Q 版形象 |
| ② 边干边说 | 按真人操作速度回放：输入、排队、提问卡选中、完成折叠 | 0.9.53 实拍逐状态截图 + 叠加层 |
| ③ 模型分工 | 模型卡发牌越落越快，落进真实槽位，再依拍亮起分工 | 手绘模型卡 + Q 版形象 + 产品内置厂商标志 |
| ④ 可恢复 | 执行轨迹向下生长，断电全黑，原地续跑 | 手绘轨迹（产品页面里没有这个视图） |
| ⑤ 三种距离 | 三张官方实拍依次划入 | 官方 README 实拍 |
| ⑥ 跨设备 | 设备节点依次点亮，手机节点展开成批准画面 | 手绘连接图与手机 |
| ⑦ Bot 群聊 | 15 位角色冒头成行，Varin 单独一拍最后登场 | 产品内置角色图 |
| 收尾 | 每章代表元素四面飞入，散开后括号合拢，全家福升起 | 复用各章元素 + 官方全家福 |

真实界面统一用 `tools/promo-capture` 以 1110×705、DPR 2 采集，或取官方 README 截图（同规格），放进窗口框。产品里不存在的视图（终端、轨迹、连接图）才手绘，手绘部分同样使用产品的色值和字体。

## 配乐系统

所有声音都由代码合成（`scripts/synth/film.mjs`），没有任何外部音频文件，所以 B 站不会触发版权识别。

| 段落 | 时间 | 和声 | 乐器 |
| --- | --- | --- | --- |
| 前奏 | 0–12s | Am → F → E | 暗 pad、时钟滴答、hi-hat、riser，末拍静音 |
| 主题 A | 12–60s | Am – F – C – G | 四拍底鼓、贝斯、拨弦琶音、侧链 pad |
| 收窄 / 断电 / 回归 | 60–72s | Dm – Am – Dm – E | 心跳低音 → 全停（只剩嗡声）→ 上电扫频、底鼓与军鼓滚奏回归 |
| 主题 B | 72–96s | Am – F – C – G | 加 clap 与主旋律，能量最高 |
| 温暖段 | 96–104s | F – G – Em – Am | 铃音琶音 + pad，鼓退后 |
| 终章 | 104–115.5s | F – E → Am(add9) | 军鼓滚奏 + riser → 静音半拍 → 最终和弦自然衰减 |

拟音规则：画面里发生什么动作就配什么声音（打字配键盘、落位配木质 tick、选中配机械 click、模型发牌连发时音量逐级递减），不用游戏提示音。全画面级冲击全片只用 3 次（揭示、恢复、品牌落定）。

## 交付物

- `out/varin-promo.mp4`：带配乐版，1920×1080 · 30fps · H.264 + AAC 48kHz 320k
- `out/varin-promo-sfx-only.mp4`：仅音效版（同一视频流换音轨），方便以后换配乐
- 封面：用收尾全家福帧（约第 3420 帧）
## 复现

```sh
npm install && npm run assets
npm run film        # 合成配乐 + 渲染两版成片到 out/
npm run sample      # 15 秒样片
npm run dev         # Studio 预览
```
