## V2 相对 V1 改了什么

| 反馈 | V2 的做法 |
| --- | --- |
| 整体太慢 | 1:55.5 → 1:29.5；①章 19 秒 → 12 秒，②③⑤⑥⑦各 8 秒；标题卡压在画面上，不再占半屏 |
| 切镜不要硬切 | 每个章节边界都是一次“承接”，见下表；只有⑤→⑥是同一个镜头接着走 |
| 0:15 之后配不上热血转场 | 品牌标志不离场：镜头从标志里拉出来，原来它就是应用标题栏的标志，光标已经在点输入框 |
| 0:15–1:00、1:12–1:35 平淡 | 加入相机运镜（推、跟、甩）、真实光标/手指点击、标题词逐拍砸入；①章结尾 20 种 Agent 墙按 32 分音符弹出 |
| 1:35–1:43 要更快、动效更足 | Bot 从屏幕中心炸开 → Varin 带冲击波砸入 → 全员一拍归队 → 群聊四条消息逐拍弹出；鼓不再退后 |
| 1:43→1:44 硬切 | Varin 头像的边框展开成收尾的藏青舞台 |
| 要有真实输入 | ①真实首页输入框里逐字打出需求、点发送；②输入框插话 + 回车排队、点选项、点提交；⑤点真实的工作台切换菜单；⑥手指在真实 Android 截图上点选项、点提交 |

## 转场（每个边界留下来、并且在动的东西）

| 边界 | 承接方式 |
| --- | --- |
| 揭示 → ① | 标志放大到与标题栏标志重合，镜头从它拉出整个窗口 |
| ① → ② | 从 Agent 墙甩镜头（带运动模糊）到下一扇窗 |
| ② → ③ | 推进模型选择器，从它“打开”一个圆形转场，模型卡从这个点发出来 |
| ③ → ④ | 纸面地板连同卡片一起掉下去，露出下面已经在跑的深色执行轨迹 |
| ④ → ⑤ | 冲击 2/3：最后一个勾选点放出圆形转场，展开成对话窗口 |
| ⑤ 内部 | 产品自己的晶格切换（`workbench-lattice.ts` 的格子尺寸与时长） |
| ⑤ → ⑥ | 同一镜头：窗口缩到左侧变成“你的电脑”，手机从右侧升起 |
| ⑥ → ⑦ | 镜头钻进手机屏幕，白场后 Bot 炸开 |
| ⑦ → 收尾 | Varin 头像框展开成藏青舞台，元素汇聚（V1 认可的部分保留） |
