## 音乐方案

原创合成，不用现成曲库，避免 B 站版权识别：

| 段落 | 小节 | 内容 |
| --- | --- | --- |
| 前奏 | 1–6 | 暗色 pad + 滴答，紧张感逐步抬升，末尾抽空 |
| 主题 A | 7–30 | 四拍底鼓 + 贝斯 + 拨弦琶音，温和、有推进力，不做 EDM 式轰炸 |
| 断电 | 31–36 | 收窄 → 全停一小节 → 心跳式回归 |
| 主题 B | 37–48 | 加入 clap 与上方旋律，全片能量最高的律动段 |
| 温暖段 | 49–52 | 铃音 + pad，配角色出场 |
| 终章 | 53–58 | riser → 最终和弦，延音收尾 |

音效同样按动作配：打字配键盘、选中配机械 click、落位配拨弦，不用游戏提示音。
